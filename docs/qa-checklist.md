# Hanji 수동 QA 체크리스트

## 패널
- [ ] ⌥Space로 열면 즉시 입력창에 커서가 있다 (클릭 불필요)
- [ ] Esc/⌥Space로 닫으면 직전 앱으로 포커스가 돌아간다
- [ ] 메뉴바 아이콘 좌클릭 토글 / 우클릭 메뉴가 동작한다
- [ ] 풀스크린 앱(예: 전체화면 Safari) 위에서도 패널이 뜬다
- [ ] 다른 앱을 클릭해도 패널이 닫히지 않고 떠 있다
- [ ] 패널이 떠 있어도 뒤 앱의 포커스를 뺏지 않는다

## 한글 IME (핵심 차별화 — 전부 통과 필수)
- [ ] 조합 중 Enter — 마지막 글자가 잘리지 않는다 ("한지" 치고 바로 Enter)
- [ ] 조합 중 ⌘F — 글자가 유실되지 않는다
- [ ] 인라인 수정에서도 위 두 항목 통과
- [ ] 자소 분리("한글"→"ㅎㅏㄴ글")가 어디에도 없다
- [ ] 구름 입력기 등 서드파티 입력기에서도 기본 동작 확인

## 검색
- [ ] 초성(ㅅㅇㄷ), 부분(사이ㄷ 조합 중), 영문 대소문자 무시 모두 동작
- [ ] 하이라이트 위치가 정확하다 (겹받침 포함 단어로 확인)
- [ ] 태그 칩 클릭 필터 + 검색어 AND 결합
- [ ] Esc 1번=검색 종료, 2번=패널 닫기

## 데이터
- [ ] 재시작 후 데이터 유지
- [ ] Backups/에 오늘자 스냅샷, 8일 지나면 7개 유지 (날짜 조작 테스트는 스킵 가능 — 단위 테스트가 커버)
- [ ] 전체 내보내기 .md가 올바르다
- [ ] 1,000자 메모, 이모지 메모, 링크 텍스트 표시 정상

## 비주얼·모션
- [ ] 라이트/다크 전환 시 한지/먹 테마가 각각 의도대로
- [ ] MaruBuri↔Pretendard 전환 반영
- [ ] '동작 줄이기' 설정 시 모든 애니메이션 제거
- [ ] 시스템 폰트 크기·해상도(레티나/비레티나)에서 흐릿함 없음

## 이월된 확인 항목 (Task 12·13에서)
- [ ] 수정 중 ⌘Z — 삭제 복구가 아니라 입력 텍스트 undo로 동작 (삭제해 둔 메모가 있는 상태에서 다른 메모 수정 중 ⌘Z)
- [ ] 더블클릭이 텍스트 단어 선택과 충돌하지 않고 수정 모드로 진입
- [ ] ⌘F로 검색 진입 시 검색 필드에 즉시 포커스
- [ ] 검색 중 패널을 단축키로 숨겼다 다시 열면 검색 상태가 남는지 (남으면 기록만 — 결함 아님, 관찰)
- [ ] 설정에서 패널 좌/우·폭 변경이 다음 열기부터 반영
- [ ] 내보내기 실패 상황 대신 정상 내보내기 1회 (md 파일 열어 확인)
- [ ] ⌥Space가 다른 앱 단축키와 충돌하는지 (충돌 시 설정에서 변경 가능한지)
