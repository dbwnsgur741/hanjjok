### 소개(description)

ㅅㅇㄷ만 쳐도 "사이드노트"가 찾아지는 메모장입니다.

카톡 '나와의 채팅'에 메모하던 습관을 그대로 Mac 메뉴바로 옮겼습니다. Option+Space를 누르면 화면 한쪽에서 종이 한 장이 미끄러져 나오고, 적고, Esc로 닫으면 하던 일로 돌아갑니다. 생각에서 기록까지 1초.

**왜 만들었나**
Mac 메모 앱은 많은데, 한글로 쓰는 사람을 위한 검색은 없었습니다. 외산 앱은 초성을 모르고, "사이ㄷ"처럼 조합 중인 글자를 치면 결과가 끊깁니다. 자모 단위로 색인해서 조합 중에도 결과가 유지되게 만들었습니다.

**하는 것**
- 초성·부분 검색 — 한글 조합 중에도 결과가 안 끊김
- 시간순 타임라인 — 폴더 계층 없이 위에서 아래로 쌓임 (#태그 + 1단계 폴더)
- 가벼운 마크다운 — 제목·굵게·인용·불릿·체크리스트, 체크는 카드에서 바로 토글
- 라이트는 한지, 다크는 먹. 본문은 마루부리 / Pretendard
- 전체 마크다운 내보내기 — 락인 없음

**안 하는 것**
계정, 서버, 동기화, 텔레메트리. 전부 내 Mac 안에만 있습니다. App Store 개인정보 라벨 "데이터 수집 안 함".

**피드백 받고 싶은 것**
1. 초성 검색이 실제 메모 습관에서 쓸모가 있는지
2. iPhone·iCloud 동기화 요청이 얼마나 되는지 — 요청이 모이면 만듭니다
3. 한지 비주얼이 "예쁘다"에서 끝나는지, 계속 쓰게 하는지

## 메이커로그 (첫 글)

제목: 카톡 '나와의 채팅'을 Mac 메뉴바로 옮겼습니다 — 초성으로 찾는 메모장 '한쪽' 출시

본문:

카톡 나와의 채팅에 메모하는 분 많으시죠. 저도 그랬는데, 정작 찾을 때가 문제였어요. 스크롤 지옥.

그래서 Mac 메뉴바에 붙는 메모장을 만들었습니다. Option+Space 누르면 화면 오른쪽에서 종이 한 장이 나오고, 적고, Esc.

핵심은 검색입니다. ㅅㅇㄷ 치면 "사이드노트"가 나오고, "사이ㄷ"처럼 아직 조합 중인 글자에서도 결과가 끊기지 않아요. 한글을 자모 단위로 풀어 색인하는 방식인데, 외산 메모 앱은 이걸 안 하더라고요.

만들면서 제일 고생한 건 한글 IME였습니다. SwiftUI 텍스트 필드는 조합 중 Enter를 치면 마지막 글자를 잃어버려요. 결국 NSTextView를 직접 잡고 조합 확정 이후에만 Enter를 처리하도록 바꿨습니다. 이 얘기는 따로 길게 쓸게요.

디자인은 라이트가 한지, 다크가 먹입니다. 쪽빛은 검색 매치에만 씁니다.

계정도 서버도 없어요. 전부 로컬. 무료.
